# 04 — วงจรป้องกันและปรับสัญญาณ Piezo

> หัวใจของ velocity ที่แม่น: piezo ไม่ได้ให้สัญญาณ DC แต่ให้ **pulse แรงสูงที่สั้นมาก**
> ถ้าต่อตรงเข้า ADC จะ (1) พัง ADC และ (2) อ่านค่ายากเพราะ pulse สั้นกว่า sampling rate

## 1. ทำไมต่อตรงไม่ได้

| เรื่อง | ตัวเลข |
|--------|--------|
| แรงดันที่ piezo 27 mm สร้างตอนตีแรง | 20–50 V peak (วัดจริงได้บ่อยที่ 30 V) |
| Absolute maximum ของ MCP3208 ที่ขา analog | −0.3 V ถึง VDD+0.3 V = **−0.3 ถึง 3.6 V** |
| ความกว้างของ pulse | 0.5–3 ms |
| Sampling rate ต่อช่องของระบบนี้ | ~1.7 kHz → **ห่างกัน 0.6 ms** |

สรุป: ต้องมี (ก) ตัวจำกัดแรงดัน (ข) ตัวจับยอด (peak hold) และ (ค) buffer

## 2. วงจรต่อช่อง (ทำ 9 ช่องเหมือนกันหมด)

```
   Piezo 27mm
   ┌────┐
   │ P1 ├──┬─────[ 1 MΩ ]─────┬──────────────────────────────┐
   │    │  │   (R_damp)       │                              │
   │ P2 ├──┴───────────────────┴──[ 1 kΩ ]──┬── D1 ──► 3V3   │

                                            ├── D2 ──► GND   │
                                            │  (clamp ล่าง)   │
                                            │                 │
                                            ├── D3 ──►┬───────┴───[ 47 nF ]── GND
                                            │  (peak) │
                                            │         └──[ 220 kΩ ]── GND
                                            │                 │
                                            │            node H (hold)

```

## 3. หน้าที่ของแต่ละชิ้น

| ชิ้นส่วน | ค่า | หน้าที่ | ถ้าไม่มี |
|----------|-----|---------|----------|
| R_damp | 1 MΩ | คายประจุ DC ของ piezo + damp resonance | ค่า DC ลอย, ช่องอ่านไม่นิ่ง |
| R_limit | 1 kΩ | จำกัดกระแสเข้า diode clamp | กระแสพุ่งทำ diode/ราง 3.3 V พัง |
| D1 | BAT54/BAT85 | clamp ยอดบวกไว้ที่ 3.3 V + Vf | ADC รับ >3.6 V → พัง |
| D2 | BAT54/BAT85 | clamp ยอดลบไว้ที่ −0.3 V | ADC รับแรงดันลบ → พัง |
| D3 | BAT54/BAT85 | half-wave peak detector | อ่านยอดไม่ได้ (pulse สั้นเกิน) |
| C_hold | 47 nF | เก็บยอดไว้ให้ ADC อ่านทัน | ค่าที่อ่านได้จะสุ่ม |
| R_hold | 220 kΩ | คายประจุ C ให้พร้อมรับครั้งถัดไป | ช่องอิ่มตัว ค้างค่าสูง |
| MCP6004 | — | buffer อิมพีแดนซ์สูง → ขับ sample cap ของ ADC | ADC อ่านผิดเพราะ source impedance สูง |
| R_adc | 100 Ω | กัน oscillation ของ op-amp กับ C ที่ขา ADC | อาจเกิด ringing |
| C_adc | 100 nF | reservoir ให้ sample-and-hold ของ MCP3208 | อ่านค่าเพี้ยนตอน scan เร็ว |

**ค่าใช้จ่ายต่อช่อง:** ~15 บาท (BAT54 2 ตัว + R 3 ตัว + C 2 ตัว + 1/4 ของ MCP6004)

## 4. คำนวณที่สำคัญ

### 4.1 กระแสตอน clamp (ป้องกัน ADC)

piezo ยอด 40 V ผ่าน R_limit 1 kΩ เข้า diode ที่ 3.6 V:

```
I = (40 − 3.6) / 1000 = 36 mA  (นาน < 1 ms)
```

BAT54 รับ forward current ได้ 200 mA → ปลอดภัย และราง 3.3 V มี C 10 µF รับประจุนี้ได้
ถ้า piezo แรงกว่านี้ (>60 V) ให้เพิ่ม R_limit เป็น 2.2 kΩ (จะ attenuate สัญญาณลงเล็กน้อย)

### 4.2 เวลาคลายของ peak hold

```
τ = R_hold × C_hold = 220 kΩ × 47 nF = 10.3 ms
```

ระบบ sample ทุก ~0.6 ms → อ่านยอดได้ภายใน 1–2 sample และ droop ระหว่างนั้น < 6%
(ถ้าใช้ 1 MΩ จะได้ τ = 47 ms → ค้างนานเกินไป ทำให้ตีถี่ ๆ แล้วค่ายังสูงอยู่)

### 4.3 เหตุผลที่ต้องมี buffer

| พารามิเตอร์ | ค่า |
|-------------|-----|
| Sample cap ของ MCP3208 | 7 pF |
| เวลาสุ่มตัวอย่างที่ 1 MHz | 1.5 clock = 1.5 µs |
| ถ้าขับจาก R_hold 220 kΩ ตรง ๆ | τ = 220 k × 7 p = 1.54 µs → **ไม่ทัน** (ต้อง ~10τ) |
| ขับด้วย MCP6004 (Rout ~ 100 Ω) | τ = 0.7 ns → ทันสบาย |

### 4.4 ความละเอียดของ velocity

```
1 count = 3.3 V / 4096 = 0.806 mV
```

- ตีเบา ๆ ได้ยอด ~300 mV = 372 counts → velocity คำนวณได้ละเอียดพอ
- ตีแรงได้ 3.0 V = 3720 counts
- threshold ที่ตั้งไว้ราว 90–130 counts (≈ 75–105 mV) จะไม่โดน noise

## 5. ถ้าอยากปรับความไวต่อแพด

เพิ่ม trimpot 10 kΩ แบบอนุกรม (เป็น attenuator) ระหว่าง piezo กับ R_limit:

```
piezo ── trimpot 10 k (ขา 1-2) ── ขา 3 ── R_limit 1 k ── ...
                     │
                    GND
```

แล้วปรับให้ทุกแพดได้ยอดใกล้เคียงกันตอนตีแรงเท่ากัน (ใช้คำสั่ง `t` ใน serial ดูค่า peak)
หรือจะใช้ระบบ **Calibration** ในเมนู (`MENU → CALIBRATE`) ซึ่งวัด noise floor แล้วตั้ง threshold ให้อัตโนมัติก็ได้

## 6. วิธีทดสอบวงจรด้วยมัลติมิเตอร์ (ก่อนต่อเข้า ADC)

1. ยังไม่ต้องต่อไฟ — วัดความต้านทาน piezo: ควรเป็นวงจรเปิด (∞) ไม่ใช่ 0 Ω (ถ้า 0 Ω = piezo ช็อต)
2. ต่อไฟแล้ว วัด DC ที่ **node H** (หลัง diode peak): ควรได้ ~0 V ตอนไม่ตี
3. ใช้ด้าม screwdriver เคาะเบา ๆ ที่ piezo แล้ววัดซ้ำ: ควรเห็นค่ากระโดดขึ้น 0.3–3 V แล้วค่อย ๆ ลดลงภายใน ~50 ms
4. ถ้าไม่ขึ้นเลย: ตรวจทิศทาง diode D3 (แถบคาธอดต้องไปทาง C_hold)
5. ถ้าค้างที่ 3.3 V ตลอด: D3 กลับด้าน หรือ C_hold ช็อต
6. ต่อเข้า ADC แล้วใช้คำสั่ง `t` (raw ADC dump) ใน serial monitor ดูค่าสด

## 7. crosstalk ระหว่างแพด

อาการ: ตี Snare แล้ว Tom ดังด้วย

วิธีแก้ (เรียงตามความได้ผล)
1. เพิ่ม threshold ของช่องที่โดนรบกวน (ทำได้ในเมนู CALIBRATE หรือแก้ `PADS[].defThreshold`)
2. แยกสายสัญญาณของแต่ละแพดออกจากกัน อย่ามัดรวม
3. ใส่ ferrite bead ที่สาย piezo แต่ละเส้น
4. ปรับ R_damp ลงเป็น 470 kΩ (ทำให้piezo ดับเร็วขึ้น)
5. ตรวจว่าตัวถังกลองไม่ได้สั่นทั้งตัว (ใส่ยางรองขา)
