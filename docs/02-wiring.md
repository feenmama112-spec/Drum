# 02 — Wiring Diagram (การต่อวงจรทุกอุปกรณ์)

> ⚠️ **ห้ามต่อ Piezo เข้า ADC โดยตรง** piezo 27 mm ตอนตีแรงจะเกิดแรงดันได้ 20–50 V
> ซึ่งเกิน absolute maximum ของ MCP3208 (VDD+0.3 V) → ชิปพังทันที
> ต้องผ่านวงจรใน `docs/04-piezo-input.md` ทุกช่อง

## 1. ภาพรวมระบบ

```
                       ┌──────────────────────────────────────────┐
   9 × Piezo ──────────►│ วงจรป้องกัน+peak hold (9 ช่อง)            │
   (Snare...Ride)       │ clamp → diode peak → R/C → buffer MCP6004│
                        └───────┬──────────────────────────────────┘
                                │ 0–3.3 V
                        ┌───────▼────────┐   SPI3   ┌──────────────┐
                        │ MCP3208 #0 (8) │◄────────►│              │
                        │ MCP3208 #1 (8) │  CS 7/21 │              │
                        └───────▲────────┘          │              │
                        Pedal pot│                  │  ESP32-S3    │
                                 │                  │  Super Mini  │
   microSD module ◄────── SPI2 ──┼──────────────────┤  (GPIO ตาราง │
                                 │                  │   docs/03)   │
   SSD1306 OLED  ◄────── I2C  ───┼──────────────────┤              │
                                 │                  │              │
   4 × ปุ่ม      ────────────────┼──────────────────┤              │
                                 │                  │              │
   PCM5102A DAC ◄──── I2S ───────┼──────────────────┤              │
        │                        │                  └──────────────┘
        ├──► PAM8403 ──► ลำโพง 8 Ω (BTL)
        └──► line out ──► ลำโพงมีไฟ / หูฟังผ่าน amp
```

## 2. ตารางต่อสายทีละอุปกรณ์

### 2.1 microSD card module (SPI)

| โมดูล | → | ESP32-S3 | หมายเหตุ |
|-------|---|----------|----------|
| VCC | → | 3V3 | ถ้าโมดูลมี LDO 5 V จะจ่าย 5 V ก็ได้ แต่ 3V3 ปลอดภัยกว่า |
| GND | → | GND | |
| CS | → | GPIO10 | |
| MOSI | → | GPIO11 | บางโมดูลพิมพ์ MOSI / DI |
| SCK | → | GPIO12 | |
| MISO | → | GPIO13 | บางโมดูลพิมพ์ MISO / DO |

### 2.2 MCP3208 #0 — แพดทั้ง 9 (DIP-16)

| ขา IC | ชื่อ | → | หมายเหตุ |
|------:|------|---|----------|
| 16 | VDD | → 3V3 | + 100 nF ไป GND |
| 15 | VREF | → 3V3 | + 10 µF ไป GND (สำคัญต่อความนิ่งของ velocity) |
| 14 | AGND | → GND (จุดรวมแอนะล็อก) | |
| 9 | DGND | → GND (จุดรวมแอนะล็อก) | |
| 13 | CLK | → GPIO4 | |
| 11 | DIN | → GPIO5 | |
| 12 | DOUT | → GPIO6 | ต่อร่วมกับ DOUT ของ chip #1 |
| 10 | CS/SHDN | → GPIO7 | |
| 1–8 | CH0–CH7 | ← เอาต์พุตของวงจร piezo | ดูหัวข้อ 4 |

### 2.3 MCP3208 #1 — Ride + Pedal + สำรอง

| ขา IC | ชื่อ | → | หมายเหตุ |
|------:|------|---|----------|
| 16 | VDD | → 3V3 | + 100 nF |
| 15 | VREF | → 3V3 | ใช้ร่วมกับ chip #0 ได้ |
| 14, 9 | AGND, DGND | → GND | |
| 13 | CLK | → GPIO4 | **ใช้ร่วม** กับ chip #0 |
| 11 | DIN | → GPIO5 | **ใช้ร่วม** |
| 12 | DOUT | → GPIO6 | **ใช้ร่วม** |
| 10 | CS/SHDN | → GPIO21 | แยก CS เท่านั้น |
| 1 | CH0 | ← Ride | |
| 2 | CH1 | ← Hi-hat pedal | wiper ของ pot |
| 3–8 | CH2–CH7 | ว่าง | ต่อ GND ผ่าน 10 kΩ |

> สองชิปใช้บัส SPI ร่วมกันได้ปลอดภัยเพราะถูกอ่านจาก task เดียว (trigger task)
> และมี CS แยกกัน — ห้ามต่อ CS ของทั้งสองชิปเข้าด้วยกัน

### 2.4 PCM5102A DAC (3-wire I2S)

| โมดูล | → | หมายเหตุ |
|-------|---|----------|
| VIN | → 5V | บอร์ดส่วนใหญ่มี AMS1117-3.3 onboard (ห้ามป้อน 5 V เข้า 3.3 V pad) |
| GND | → GND | |
| BCK | → GPIO15 | |
| LRCK (LCK) | → GPIO16 | |
| DIN | → GPIO17 | |
| SCK | → **GND** | ใช้ internal PLL (ไม่ต้องต่อ MCLK) |
| FLT | → **GND** | normal filter |
| DEMP | → **GND** | ปิด de-emphasis |
| XSMT | → **3V3** | soft mute ต้อง HIGH ไม่งั้นเงียบ |
| FMT | → **GND** | เลือก I2S (ถ้า HIGH จะเป็น left-justified → เสียงเพี้ยน) |

บอร์ดม่วงส่วนใหญ่มีจั๊มเปอร์บัดกรีด้านหลัง (FLT/DEMP/XSMT/FMT) — **ต้องบัดกรีให้ครบตามตารางนี้**

### 2.5 SSD1306 OLED (I2C)

| จอ | → | ESP32-S3 |
|----|---|----------|
| VCC | → 3V3 | |
| GND | → GND | |
| SDA | → GPIO8 | pull-up 4.7 kΩ ถ้าจอไม่มี |
| SCL | → GPIO9 | pull-up 4.7 kΩ |

### 2.6 ปุ่มทั้ง 4

วิธีเดียวกันหมด: ขาหนึ่ง → GPIO, อีกขา → GND (ใช้ pull-up ภายใน ไม่ต้องเพิ่ม R)

| ปุ่ม | GPIO | หน้าที |
|------|-----:|--------|
| KIT | 1 | กดสั้น = คิทถัดไป, กดค้าง = คิทก่อนหน้า |
| MENU | 2 | กดสั้น = เข้าเมนู / ยืนยัน, กดค้าง = ออก |
| VOL− | 14 | ลดเสียง / เลื่อนเมนูลง / เลือกแพด |
| VOL+ | 18 | เพิ่มเสียง / เลื่อนเมนูขึ้น / เลือกแพด |

### 2.7 Hi-hat pedal

**แบบ potentiometer 10 kΩ (ง่ายสุด)**

```
3V3 ──┬── pot ขา 1
      │
      ├── pot ขา 3 ── GND
      │
      └── wiper (ขา 2) ──┬── MCP3208 #1 CH1
                         └── 100 nF ── GND   (กรอง noise)
```

**แบบ Hall sensor SS49E + แม่เหล็ก** (แนะนำถ้าอยากให้ทนกว่า)
SS49E ทำงานที่ 3.3 V ได้ (2.7–6.5 V) และเอาต์พุตอยู่ในช่วง 0.85–2.5 V → ต่อเข้า ADC ได้ตรง

```
3V3 ── SS49E VCC
GND ── SS49E GND
       SS49E OUT ──┬── MCP3208 #1 CH1
                   └── 100 nF ── GND
```

> ถ้าใช้ **SS495A** (ต้องจ่าย 5 V) เอาต์พุตจะเกิน 3.3 V → ต้องมี divider 10 k/20 k ก่อนเข้า ADC
> และถ้าเหยียบแล้วค่าตรงข้าม (ปิดสุดกลับอ่านเป็น 100%) ให้ตั้ง `#define HH_PEDAL_INVERT 1` ใน `include/config.h`

### 2.8 ภาคขยายเสียง / หูฟัง

```
PCM5102A OUT L/R (2.1 Vrms, ground-centered)
        │
        ├── 1 µF ── 10 kΩ ──┬── 10 kΩ ── GND   (ลดเหลือ ~1 Vrms)
        │                   └── PAM8403 IN L
        │                    (ช่อง R ทำเหมือนกัน)
        └── 220 Ω ──────────── แจ็ค 3.5 mm (LINE OUT) ──► ลำโพงมีไฟ / amp
```

| เรื่อง | คำอธิบาย |
|--------|----------|
| PAM8403 เป็น **BTL** | ขั้ว OUT- ทั้งสองข้าง **ห้ามต่อถึงกันหรือลง GND** — ถ้าต่อแจ็คหูฟังแบบร่วมกราวด์ amp จะพัง |
| ลำโพง | 8 Ω 3 W ต่อระหว่าง OUT+ กับ OUT− ของช่องเดียวกัน |
| หูฟัง | ห้ามต่อตรงกับ PAM8403; ใช้ line-out ของ PCM5102A ผ่าน 220 Ω (สำหรับหูฟัง 64 Ω ขึ้นไป) หรือเพิ่มบอร์ดหูฟัง PAM8908/TPA6132 |
| เสียงจี่ | ถ้ามีจี่ ให้แยก GND แอนะล็อก (ดูหัวข้อ 5) และใส่ ferrite bead ที่สาย 5 V ของ PAM8403 |

## 3. การจ่ายไฟ

| ส่วน | แหล่งจ่าย | หมายเหตุ |
|------|-----------|----------|
| ESP32-S3, SD, OLED | 3V3 ของบอร์ด (จาก USB) | กินรวม ~150 mA |
| PCM5102A | 5 V (USB) → LDO บนบอร์ด | |
| PAM8403 | 5 V (USB) | กระแสสูงสุด ~700 mA ตอนดังมาก — USB ต้องจ่ายไหว |
| วงจรแอนะล็อก + MCP3208 | 3V3 (แนะนำ LDO แยก TLV70233) | ถ้าใช้ 3V3 ร่วมกับดิจิทัลจะมี noise เข้า velocity |

## 4. สายจาก piezo เข้าเบอร์

- ใช้ **สาย 2 แกนมีชีลด์** ต่อ: แกนใน = สัญญาณ, อีกแกน = GND, ชีลด์ = ต่อ GND ด้านบอร์ด **ข้างเดียว**
- ตัด/บัดกรีที่ตัว piezo แล้วปิดด้วยกาวร้อนกันลั่น
- ความยาวไม่ควรเกิน 1.5 m และ **ห้ามเดินพาดสาย I2S/SPI**

## 5. กราวด์ (สำคัญต่อคุณภาพเสียงและ velocity)

```
                       ┌──────────── จุดรวม GND (star) ────────────┐
   GND ดิจิทัล  ────────┤                                            ├──── GND แอนะล็อก
   (ESP32, SD, OLED,    │                                            │     (MCP3208 AGND/DGND,
    I2S, ปุ่ม)          │                                            │      op-amp, ชีลด์ piezo)
                       └────────────────────────────────────────────┘
                                     │
                                   GND หลัก (USB)
```

- เดิน GND ของวงจรแอนะล็อกแยกออกมา แล้วไปรวมที่จุดเดียวใต้บอร์ด
- วาง 100 nF ที่ขา VDD ของ MCP3208 ทุกตัว และ 10 µF ที่ VREF
- ถ้ายังมี noise ให้ใส่ ferrite bead คั่นระหว่าง GND สองฝั่ง

## 6. เวอร์ชันประหยัด (MCP3208 ตัวเดียว, ไม่แนะนำ)

ถ้ามี MCP3208 ตัวเดียว จะได้แค่ 8 ช่อง → **ต้องลดเหลือ 8 แพด และย้าย pedal ไป ADC ของ ESP32**
firmware ที่ให้มาในชุดนี้ตั้งไว้สำหรับ 2 ชิป ถ้าจะใช้ 1 ชิปต้องแก้ 3 จุด:

1. `src/core/kit_defs.cpp` — ลบ `PAD_RIDE` ออกจากตาราง `PADS[]` (หรือตั้ง chip เป็น 0 ซ้ำ)
2. `src/app/trigger_engine.cpp` — ใน `taskLoop()` เปลี่ยนการอ่าน pedal จาก
   `raw_[PEDAL_CHIP][PEDAL_CHANNEL]` เป็น `analogRead(3)` (GPIO3 = ADC1_CH2) และ `analogReadResolution(12)`
3. `include/config.h` — ตั้ง `AUDIO_MAX_VOICES` เท่าเดิมได้ แต่ปิด Ride ในเมนู TEST

> วิธีนี้ไม่ได้ทดสอบมากับฮาร์ดแวร์จริงในชุดนี้ — ถ้าทำได้แนะนำให้เพิ่ม MCP3208 ตัวที่สอง (130 บาท)
> เพราะได้ Ride และ pedal พร้อมกันโดยไม่ต้องแก้โค้ด
